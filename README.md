# Training

A progressive learning journey organized by weeks and days.

## Structure

This repository contains structured training modules organized by week:

- **Week 1**: Core fundamentals including Node.js streams, performance analysis, API investigation, and project configuration
- **Week 2**: Web development basics with HTML, CSS and JS
- **Week 3**: Advanced frontend development using Tailwind CSS and Next.js
- **Week 4**: Backend development with Node.js, Express, and MongoDB
- **Week 5**: Server Side Foundations with Docker & DevOps Basics

## Getting Started

Each week contains daily exercises and projects. Navigate to the relevant week folder to find specific learning modules.
