# Tool-Calling Agent Architecture

## Overview

This project implements a tool-calling AI agent system capable of
analyzing datasets, executing Python code, and interacting with
databases using specialized agents.\
The architecture demonstrates how an LLM can orchestrate multiple tools
to solve a user request.

The system follows a planner → tool execution → result pipeline
where each tool has a specific responsibility.

## System Architecture

User Query\
↓\
Planner Agent (Orchestrator)\
↓\
File Agent (Reads CSV/TXT files)\
↓\
Code Executor (Runs Python analysis)\
↓\
DB Agent (Optional database queries)\
↓\
Final Answer

## Agents and Tools

### 1. File Agent

Purpose: Read and process local files.

Supported formats: - `.csv` - `.txt`

Responsibilities: - Load file contents - Return structured data -
Provide dataset preview to other agents

Example usage:

``` python
file_data = file_agent.read_file("sales.csv")
```

### 2. Code Executor Agent

Purpose: Execute dynamically generated Python code.

Responsibilities: - Receive Python code generated by the LLM - Execute
the code safely - Return output or error messages

Example:

``` python
result = code_executor.run_code(python_code)
```

Typical tasks: - Dataset analysis - Aggregation and statistics - Data
filtering - Insight generation

### 3. DB Agent

Purpose: Execute SQL queries on SQLite databases.

Responsibilities: - Connect to SQLite databases - Execute SQL queries -
Return structured query results

Example:

``` python
db_agent.connect("sales.db")
db_agent.execute_query("SELECT * FROM sales LIMIT 5")
```

## Tool Orchestration

The Planner Agent analyzes the user query and generates a tool
execution plan.

Example tool plan:

``` json
{
 "steps":[
   {"tool":"file_agent","input":"sales.csv"},
   {"tool":"code_executor","task":"find top 5 products by sales"}
 ]
}
```


## Example Workflow

User request:

    Analyze sales.csv and generate top 5 insights

Execution pipeline:

1.  Planner identifies required tools
2.  File Agent loads the dataset
3.  Code Executor runs Python analysis
4.  Results are returned to the user

Example result:

    Top 5 Products by Sales:
    Jacket
    Cap
    Laptop
    Monitor
    Printer

## Key Capabilities

-   Tool selection using LLM planning
-   Automatic Python code generation
-   CSV dataset analysis
-   SQLite database querying
-   Autonomous tool execution pipeline
